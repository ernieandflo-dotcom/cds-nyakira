## Fonctionnalités

- **5 langues** : Français · Kirundi · English · Swahili · 中文  
  La langue choisie est mémorisée (localStorage).
- **Mobile-first** : Design responsive, menu adaptatif
- **SEO** : Balises title, meta description, lang, hiérarchie H1/H2
- **Accessibilité** : Contraste WCAG AA, navigation au clavier

## Hébergement GitHub Pages

1. Créer un repo GitHub (ex: `cds-nyakira`)
2. Pousser tous les fichiers à la racine
3. Dans Settings → Pages → Source : `main` / `/(root)`
4. Le site sera disponible à `https://[votre-user].github.io/cds-nyakira/`
